# Cult Quant 2026: Nifty 50 Investment Intelligence

Welcome to the **Cult Quant 2026** repository. This project is a comprehensive, institutional-grade algorithmic investment platform designed specifically for the Nifty 50 equity universe. It bridges the gap between raw market microstructure and actionable portfolio allocation using a "Quantamental" framework—merging advanced Machine Learning (LightGBM/XGBoost) with robust Modern Portfolio Theory (MPT) risk analytics.

This repository contains all source code, model artifacts, configuration files, and documentation required to reproduce the analytics and run the interactive Streamlit dashboard.

## Project Overview
Traditional heuristic trading models and linear factor models often fail to capture the non-linear, heteroskedastic nature of modern financial markets. This project solves this limitation by:
* **Predicting Alpha:** Using histogram-based gradient boosting ensembles (LightGBM) to forecast expected returns based on engineered momentum, trend, and volatility features.
* **Managing Risk:** Utilizing Monte Carlo simulations to construct an Empirical Efficient Frontier and isolate mathematically optimal portfolios (Conservative, Balanced, Aggressive).
* **Ensuring Transparency:** Deploying Explainable AI (XAI) overlays, including Isolation Forests for anomaly detection and Natural Language Generation (NLG) for human-readable trade rationales.
